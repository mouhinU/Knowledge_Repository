质量评分计算规则

                
由「内容审核 Agent」按 6 个维度独立打分后加权汇总

            
        

        

            

                

                    维度权重评估要点
                

                
知识准确性25%题目与答案是否与知识点一致、有无事实错误

                
知识点覆盖25%是否均匀覆盖主要知识点、有无遗漏

                
题目表述15%题干是否清晰无歧义、选项是否合理

                
题型合理性15%各题型设置是否恰当、题量是否合理

                
难度适当性10%难度是否符合要求、梯度是否合理

                
格式规范性10%排版、编号、分值标注是否规范

            

            

                
计算公式

                总分 = 准确性×0.25 + 覆盖×0.25 + 表述×0.15 + 题型×0.15 + 难度×0.10 + 格式×0.10（四舍五入，取值 0–100）
            

            

                ≥ 80 优
                60 – 79 良
                < 60 需改进
            

            
说明：每份试卷的具体维度得分在生成时已随评分一并落库，可在「查看」详情的「评分构成」中核对加权过程；若模型未按要求输出明细，系统回退解析总分，仍无法识别时默认计 70 分。
